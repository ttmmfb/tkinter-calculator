# Калькулятор на Python (Tkinter)

Простой и стильный графический калькулятор с поддержкой скобок, инженерных функций и управления с клавиатуры, написанный на стандартной библиотеке `tkinter`.

## Возможности
- **Базовые операции:** сложение (`+`), вычитание (`-`), умножение (`×`), деление (`÷`), возведение в степень (`^`).
- **Инженерные функции:** вычисление квадратного корня (`√(`), использование скобок и подстановка последнего результата (`Ans`).
- **Удобный ввод:** поддержка физической клавиатуры (цифры, знаки, `Enter` для расчёта, `Backspace` для удаления) и защита от ввода некорректных символов.
- **Обработка ошибок:** понятные всплывающие уведомления при делении на ноль или синтаксических ошибках в выражении.

## Установка и запуск

Проект использует только стандартные библиотеки Python (`tkinter`, `math`), поэтому установка дополнительных пакетов не требуется.

1. Убедитесь, что у вас установлен **Python 3.x**.

2. Создайте окружение:
   ```bash
   conda create -n gui
   ```
   
3. Клонируйте репозиторий или скачайте файл с кодом:
   ```bash
   git clone https://github.com/ttmmfb/tkinter-calculator
   cd tkinter-calculator
   ```
4. Запустите программу:
   ```bash
   python calculator.py
   ```
   *(На Linux может потребоваться установка системного пакета `python3-tk`, если он не идёт в комплекте с Python).*

## Использование
- Вводите выражение с помощью кнопок интерфейса или с клавиатуры.
- Для вычисления корня нажмите кнопку `√` (она автоматически откроет скобку `√(`), введите число и не забудьте закрыть скобку `)`.
- Используйте кнопку `Ans`, чтобы вставить результат предыдущего вычисления в новое выражение.
- Нажмите `=` или клавишу `Enter` для получения результата.
